# Ventilation & CO2 Calculator

เครื่องคำนวณ CO2 และปริมาณลมบริสุทธิ์ สำหรับงานออกแบบระบบระบายอากาศ

## ที่มาของข้อมูล
- ASHRAE Standard 62.1 Table 6-1 — หมวดพื้นที่ Rp, Ra, ความหนาแน่นมาตรฐาน, เพดาน CO2
- ASHRAE Standard 62.1 Appendix D — สมการ D-1
- ASHRAE Handbook Fundamentals 2017 Ch.9 Table 4 — อัตราปล่อย CO2 ตามกิจกรรม
- กฎกระทรวงฉบับที่ 39 (พ.ศ. 2537) — อัตราการระบายอากาศตามกฎหมายไทย

## การใช้งาน
เปิด `index.html` ได้เลย ไม่มี dependency ภายนอก ไม่ต้อง build ใช้งานออฟไลน์ได้

## โครงสร้าง
ไฟล์เดียวจบ ทั้ง HTML, CSS และ JavaScript อยู่ใน `index.html`
